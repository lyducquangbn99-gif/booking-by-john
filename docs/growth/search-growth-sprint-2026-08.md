## Weekly measurement rhythm

Review Search Console every Monday using the latest complete seven-day period and compare with the preceding seven days.

Record for each priority page:

- impressions;
- clicks;
- CTR;
- average position;
- top queries;
- countries;
- website inquiries attributed to the page or its CTA source.

## Decision rules

- High impressions, position 8–20, low CTR: improve title and description before adding content.
- High impressions, position 21–50: strengthen the answer, internal links and query coverage.
- Impressions rising but no inquiry: improve the quote CTA and reduce form friction.
- No impressions after 28 days: review search intent and internal linking; do not create language variants merely to increase page count.
- A new landing page requires evidence from Search Console, a real inquiry, or repeated sales demand.
