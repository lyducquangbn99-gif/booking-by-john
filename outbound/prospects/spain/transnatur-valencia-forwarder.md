Ask for:
1. Vietnam POL / pickup location.
2. Valencia or other Spain POD/final delivery point.
3. FCL/LCL/air and equipment if applicable.
4. Commodity, HS code if available, weight/CBM and package count.
5. Cargo-ready date.
6. Incoterm.
7. Any special handling, customs, DG, reefer or delivery constraints.
